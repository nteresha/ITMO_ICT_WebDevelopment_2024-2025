Задание №3. Агрегация и аннотация запросов

Необходимо реализовать следующие запросы c применением описанных методов: - Вывести дату выдачи самого старшего водительского удостоверения - Указать самую позднюю дату владения машиной, имеющую какую-то из существующих моделей в базе - Вывести количество машин для каждого водителя - Подсчитать количество машин каждой марки - Отсортировать всех автовладельцев по дате выдачи удостоверения
